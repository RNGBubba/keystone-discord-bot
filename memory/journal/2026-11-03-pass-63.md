# Pass 63 — P7: the command copy gets one owner and per-declaration keys

**Date:** 2026-11-03
**Phase:** P7
**Carrier:** `packages/i18n`, `apps/bot/src/adapt.ts`, the command modules and
`probe:live`. No new package, command, table or feature.

This is a correction pass for the four-dimension audit of pass 62. It fixes the
defects the audit named and adds no capability.

## What changed

- **Option keys can now express two subcommands.** A single
  `command.<root>.option.<name>` key had to serve every declaration of that
  option, so `setup module`, `appeal case` and `logging channel` each described
  one of their two subcommands wrongly. A subcommand's own key
  (`command.<root>.<sub>.option.<name>`) is now consulted first and the shared
  root key is the default. Only those three options needed specific keys; the
  coverage test derives the expected key set from the registry and fails if a
  shared key is used where siblings differ, if a specific key is left behind
  after the descriptions converge, or if German is missing for either.
- **English left the catalog.** The audit showed three English rows had been
  captured before the definitions changed, and that roughly half of
  `command-copy.ts` restated the registry. The English command map is gone: a
  command definition is the English sentence, and the adapter already renders
  the definition for `en`. That removes the class of bug rather than testing
  for it — there is no second English copy to drift. The German command copy
  moved into `de.ts`, so German has exactly one owner.
- **The half-German daily refusal is two lines.** `EconomyService` owns its
  refusal sentence and returns it in English; `/rank daily` now puts that
  sentence on its own line and the translated balance on the next, instead of
  splicing "Guthaben" into it. The generic transfer/purchase/gamble fallbacks
  became catalog keys, so the translated files no longer hide English literals
  inside ternaries.
- **The changelog says what it is.** In a non-English guild, `/help changelog`
  renders a translated note that the entries stay English, and displays
  `Pass 62` rather than the machine id `pass-62`. English history is not
  silently wrapped in German labels.
- **Dead seams removed.** `localeFor` was exported and never used; the German
  `error.guildOnly` could never be reached because a guild-only refusal has no
  guild locale. Both are gone. `guildLocale` now calls the settings `get` when
  the source has it, so `/rank` and `/ticket` read the setup row instead of
  listing and schema-parsing all 12 modules.
- **The enforcement map covers every module.** The per-file classification now
  discovers every `modules/*/src/commands/*.ts` file (24 files: 6 translated, 18
  deliberately English-only with a reason), so the claim in AGENTS.md and the
  README is true for the whole tree, not just diagnostics and community.
- **The probe asserts what it claims.** `command-copy-localization` now also
  drives `/rank leaderboard` (matching the seeded `levels` row), the `Rank card`
  user menu, `/ticket stats`, and the same stats command without `ManageGuild`
  (a German permission refusal). The probe count stays 27 because the check was
  extended, not multiplied.

## What we tried and rejected

- **A key per subcommand for every option.** Rejected: it would add 131 German
  strings that repeat what siblings already say, for no difference in copy. The
  specific key is used exactly when the texts differ, and the invariant is
  enforced.
- **Keeping the English map and asserting equality with the definitions.** That
  was the audit's proposed assertion; removing the map is stronger. A checked
  mirror can pass the assertion and still be edited in two places; one source
  cannot.
- **Translating the changelog summaries.** Rejected: it would create a second
  history that drifts from the journal and the release notes, and the entries
  are the bot's own record. The embed states why they are English.
- **Translating the service's economy reasons at the command layer.** Rejected:
  the rule and its sentence belong to `EconomyService`; the command now keeps
  them whole on their own line. The reasons remain English and are named here.
